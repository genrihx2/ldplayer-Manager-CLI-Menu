# LDManager v2.0.1 — CLI-меню для LDPlayer Emulator

Интерактивное PowerShell-меню для управления **локальными инстансами эмулятора LDPlayer** на вашем компьютере через официальный консольный интерфейс `ldconsole.exe` и `adb.exe`.

> **Открытый исходный код.** Скрипт предназначен исключительно для управления локальными инстансами LDPlayer Emulator на вашем компьютере. Функции подмены устройства (IMEI/Android ID/MAC) и смены SIM-страны предназначены для приватности и тестирования приложений на собственных инстансах. Полное объяснение — в разделе [«Примечание для AV-аналитиков»](#примечание-для-av-аналитиков-note-for-av-analysts) ниже.

---

## Возможности

- 🚀 **Запуск, выключение, перезагрузка** эмулятора (и всех инстансов сразу)
- 🐑 **Клонирование инстансов**
- 🗑️ **Удаление инстансов** (с двойным подтверждением)
- ✏️ **Переименование инстансов**
- 📦 **Установка и удаление приложений (APK)** — через `ldconsole installapp` и `adb install`
- 📱 **ADB-команды** — произвольные shell-команды, список устройств, перезапуск ADB-сервера
- 🧹 **Очистка данных приложения** (`pm clear`), **force stop**, запуск приложения
- 🎭 **Подмена модели устройства** (brand / model / код модели)
- 📶 **Смена оператора/SIM-страны** (MCC/MNC, телефонный код страны) — **53 пресета + кастом**; IMSI генерируется под выбранный MCC/MNC, номер телефона — под телефонный код страны
- 🎲 **Генерация случайных IMEI** (с контрольной суммой Луна) **/ Android ID / MAC** (+ IMSI, SIM serial/ICCID, производитель+модель, номер телефона; сброс в `auto`)
- 📸 **Скриншоты эмулятора через ADB** (`screencap` → PNG на рабочий стол)
- 🎬 **Запись экрана** (`screenrecord`, до 180 с, → MP4)
- 📁 **Передача файлов push/pull** между PC и эмулятором
- 💻 **Интерактивная ADB-сессия** (прямой shell)
- 🔐 **Цифровая подпись скрипта** (self-signed CodeSigning сертификат, `Set-AuthenticodeSignature`)
- 🪟 **Управление окнами** (показать/скрыть через Win32 `ShowWindow`, расставить через `sortWnd`)
- 🔄 **Массовые операции** (запуск/остановка/перезапуск всех, случайная идентификация для всех остановленных)
- 📋 **Просмотр логов** — статические файлы LDPlayer + `adb logcat`: снапшот, live-стрим, фильтр по уровню (V/D/I/W/E/F) и тегу
- 🛡️ **Менеджер GitHub-токена** (DPAPI-шифрование, проверка через `api.github.com/user`)
- 🌐 **Веб-скрейпинг (Sieve)** — сбор данных со страниц и документов, скачивание результатов, дозапросы; ключ `SIEVE_API_KEY` хранится через DPAPI
- 📊 **Информация о версиях** (скрипт, ldconsole, adb, PowerShell, Windows, статус подписи)
- ⚡ **Автообновление из GitHub** (сверка версии в raw-файле, резервная копия перед заменой)
- 🗄️ **Загрузка репозитория** (git clone, ZIP + распаковка, отдельный файл)

## Требования

- Windows 10/11
- PowerShell 5.1+ (Windows PowerShell) или PowerShell 7+
- Установленный [LDPlayer](https://www.ldplayer.net/) (LDPlayer 9 / 14 и новее)
- Опционально: `adb.exe` из Android platform-tools — иначе используется adb из папки LDPlayer
- Опционально: `git.exe` в PATH — для пункта «git clone»
- Опционально: GitHub Personal Access Token — для приватных репозиториев и больших запросов к API

## Установка и запуск

```powershell
git clone https://github.com/genrihx2/ldplayer-Manager-CLI-Menu.git
cd ldplayer-Manager-CLI-Menu

powershell -ExecutionPolicy Bypass -File .\LDManager.ps1
```

Или щёлкните правой кнопкой по `LDManager.ps1` → **«Выполнить с помощью PowerShell»**.

При первом запуске скрипт сам найдёт `ldconsole.exe` (по запущенному процессу эмулятора, записям реестра или типичным путям установки — включая `C:\LDPlayer\LDPlayer14`) и `adb.exe` (сначала в папке LDPlayer). Пути сохраняются в `LDManager.config.json` рядом со скриптом; можно задать вручную в меню **[S] Настройки**.

## Секреты в Infisical

Локальные секреты можно хранить не на диске, а централизованно в [Infisical](https://infisical.com) и передавать их скрипту через переменные окружения. Сам код ничего не знает о Infisical: он по-прежнему читает `$env:SIEVE_API_KEY` — просто переменную подставляет обёртка `infisical run`, поэтому менять скрипт не нужно.

1. **Аккаунт и проект.** Зарегистрируйтесь на [app.infisical.com](https://app.infisical.com), создайте проект (например, `ldplayer-manager`). В проекте уже есть среды Development, Staging и Production; для локального запуска используется Development.

3. **CLI.** Установите CLI и войдите:

   ```powershell
   winget install infisical
   infisical login
   ```

## Как это работает

Скрипт — надстройка над официальными утилитами:

- `ldconsole.exe` — все операции с инстансами (`list2`, `launch`, `quit`, `copy`, `remove`, `modify`, `backup`, `restore`, `action`, `locate` и т. д.);
- `adb.exe` — отладка запущенных инстансов (порт инстанса = `5555 + index × 2`), `pm clear`, `am force-stop`, `screencap`, `screenrecord`, `logcat`, `push/pull`;
- Win32 API (`user32.dll` `ShowWindow`) — показать/скрыть окна;
- `New-SelfSignedCertificate` + `Set-AuthenticodeSignature` — подпись скрипта;
- Windows DPAPI (`ConvertFrom-SecureString`) — шифрование GitHub-токена;
- `Invoke-WebRequest` / `Invoke-RestMethod` — только при явном выборе пунктов GitHub (обновление, загрузка репозитория, проверка токена) и пунктов Sieve (веб-скрейпинг).

Изменение идентификаторов выполняется штатной командой `ldconsole modify --imei/--imsi/--simserial/--androidid/--mac/--manufacturer/--model/--pnumber` и записывается в конфиг виртуальной машины `vms\leidianN\config.ini` вашей установки LDPlayer. Для применения требуется перезапуск инстанса — скрипт предложит сделать это сам.

> **О коде модели:** у `ldconsole modify` нет отдельного поля «код модели» — используется поле `model`. Значение «код модели» в меню применяет это же поле (большинство приложений читают именно `ro.product.model`).

## Веб-скрейпинг (Sieve)

Пункт **[x] Скрейпинг сайтов (Sieve)** — интеграция API [Sieve](https://scrape.usesieve.com). Позволяет в обычном языке описать, что извлечь со страницы, получить данные и файлы, скачать их локально и задать дозапросы.

- **Ключ.** Без ключа ничего не делается и поведение скрипта не меняется. Подключить ключ можно в меню: `[x] → [3] Ключ / кредиты → [1]` — вход по коду устройства (ссылка и код показываются в консоли, подтверждение — в браузере; скрипт ничего не делает за вас). Ключ сохраняется в `LDManager.config.json` зашифрованным через Windows DPAPI (CurrentUser), в открытом виде не выводится и не логируется. Если вход по коду недоступен, ключ можно вставить вручную: создайте его на сайте (`Settings → API keys`) и используйте `[x] → [3] → [4]`.
- **Переменная окружения.** Ключ также можно передать через `SIEVE_API_KEY` — она имеет приоритет над сохранённым; для локального запуска её удобно подставлять через Infisical — см. [«Секреты в Infisical»](#секреты-в-infisical).
- **Роль ключа.** Ключ даёт полный доступ к аккаунту и не имеет скоупов, поэтому он только для серверной стороны и никогда не попадает в браузеры, логи, аналитику, отчёты об ошибках или git.
- **Запуски.** `session_id` сохраняется в конфиг до всего остального, поэтому после сбоя опрос можно продолжить из пункта **[2] Мои запуски**, а не создавать дубль (повтор POST на таймауте/сетевой ошибке не выполняется намеренно).
- **Документы.** Можно начать сбор как по URL страниц, так и загрузив локальный документ (multipart, поле `file`).
- **Кредиты.** Принятые запуски расходуют кредиты; баланс смотрите в `[x] → [3] Ключ / кредиты` (GET `/api/me/credits`).

## Примечание для AV-аналитиков (Note for AV analysts)

**Резюме:** это легитимная локальная утилита автоматизации. Она не содержит вредоносного кода и не осуществляет вредоносного поведения.

1. **Назначение.** Скрипт — интерактивная оболочка (меню) над официальным CLI `ldconsole.exe` и `adb.exe`, поставляемыми вместе с LDPlayer / Android SDK. Каждое действие пользователя транслируется в соответствующий вызов этих утилит из папки установки на машине пользователя.

2. **Функции генерации идентификаторов и смены SIM-страны — почему они есть и что делают.** LDPlayer официально поддерживает параметр `modify --imei/--androidid/--mac/--imsi/--simserial <значение|auto>` — это штатная возможность эмулятора, описанная в документации производителя (приватность, тестирование приложений в разных «устройствах»). Скрипт лишь формирует корректные по формату значения (15-значный IMEI с контрольной цифрой Луна, 16-символьный hex Android ID, локально администрируемый MAC `x2:x*:*`, IMSI с префиксом выбранного MCC/MNC, ICCID с префиксом 89) и передаёт их штатной команде. Список пресетов стран — это справочные коды ITU (MCC/MNC), применяемые ТОЛЬКО к конфигу локальной виртуальной машины. Никакое реальное оборудование не затрагивается, сеть не сканируется, реальные операторы не используются.

3. **Отсутствие вредоносного поведения.** В коде нет: обфускации, Base64-полезных нагрузок, техник закрепления (persistence), доступа к учётным данным, инъекций в процессы, обхода UAC, шифрования файлов, сбора и отправки данных. Единственные внешние исполняемые файлы — `ldconsole.exe`, `adb.exe`, `git.exe` (по запросу пользователя) с машины пользователя.

4. **Сетевая активность — единственная и явная.** Исходящие HTTP-запросы выполняются только при выборе пользователем соответствующих пунктов меню и адресованы только `api.github.com` и `raw.githubusercontent.com` (проверка версии, автообновление, загрузка репозитория, проверка токена), `github.com` (ZIP) и — только при работе с пунктами Sieve — `scrape.usesieve.com`. Автоматических соединений при старте нет. GitHub-токен и ключ `SIEVE_API_KEY`, если пользователь их сохранил, хранятся в `LDManager.config.json` в виде, зашифрованном через Windows DPAPI (CurrentUser), и передаются только в заголовке Authorization к соответствующему сервису. Ключи никогда не выводятся в консоль и не пишутся в логи.

5. **Побочные эффекты.** Чтение/запись: `LDManager.config.json`, конфиги инстансов LDPlayer (`vms\leidianN\config.ini`), скриншоты/записи/резервные копии, создаваемые по явному запросу пользователя, сертификат в хранилище Cert:\CurrentUser\My (только при явном запросе подписи). Запуск процессов: только `ldconsole.exe`, `adb.exe`, опционально `git.exe`.

6. **Легитимные сценарии использования.** Автоматизация фермы локальных эмуляторов для разработки/тестирования приложений, приватность тестовых устройств, QA-проверки на разных «моделях» и «странах» без реального железа.

7. **Ответственное использование.** Подмена идентификаторов и локаций не должна применяться для обхода блокировок, мошенничества, массовой регистрации аккаунтов или нарушения условий обслуживания третьих сторон. Ответственность за использование несёт пользователь.

## История версий

### v2.0.1

- **Исправлено автообновление и «Проверить обновления»**: версия ищется в `LDManager.core.ps1` (где она и задаётся), а не в точке входа `LDManager.ps1`; раньше проверка всегда падала с «Не удалось получить версию из GitHub».
- **Исправлен поиск `ldconsole.exe`**: из реестра больше не берётся `DisplayIcon` (= `dnplayer.exe`, GUI) как путь к консоли — вместо него используется `ldconsole.exe` из папки установки. Раньше из-за этого список инстансов был пуст, а команды запуска открывали окно GUI.
- **Самообновление обновляет все файлы** (`LDManager.ps1`, `LDManager.core.ps1`, `LD.Sieve.ps1`), резервные копии складываются в папку `LDManager.backup_*`.
- **Секреты**: добавлены `.env.example` и раздел «Секреты в Infisical» в README; `.env` добавлен в `.gitignore`.

### v2.0.0

- Первый релиз: управление инстансами, приложения, конфигурация, идентификация устройства, ADB, логи, окна, массовые операции, резервные копии, GitHub-токен (DPAPI), Sieve.
