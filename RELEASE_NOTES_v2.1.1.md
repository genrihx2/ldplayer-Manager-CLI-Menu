# LDManager v2.1.1

Изменения с v2.1.0.

## Изменения

- Исправлено: в пункте `[o] Оптимизация → [1] Показать текущие настройки и пресеты` строка «Компьютер : ядер N, RAM …» выводила пустое число ядер. В одном месте осталась ссылка на `$host` — read-only автоматическая переменная PowerShell, у которой нет свойства `Cores`. Теперь везде используется `$machine`.

## Обновление

Вариант 1 — в самом меню: `[u] Обновить LDManager` (или `[g] GitHub → [3] Автообновление скрипта из GitHub`).

Вариант 2 — вручную: скачайте ZIP релиза и замените `LDManager.ps1`, `LDManager.core.ps1`, `LD.Sieve.ps1`.

> После замены файлов, если включена строгая политика выполнения (AllSigned), подпишите скрипты заново через меню `[s]`.
