# LDManager v2.0.9

Изменения с v2.0.8.

## Изменения

- Исправлено: `-LoadOnly` в ядре не работал. Параметр был объявлен, но нигде не проверялся, поэтому подключение `LDManager.core.ps1 -LoadOnly` (тесты, диагностика, сторонние скрипты) запускало меню и висело в ожидании ввода. Авто-запуск обёрнут в проверку, а точка входа отрезает блок по явной строке-маркеру вместо поиска `try {`.
- Убрано дублирование формулы ADB-порта: `Resolve-AdbPort` использует `Get-AdbTargetPort`, а не собственную копию формулы.
- Удалена мёртвая функция `Get-ReleaseTag` — она выглядела как код выбора ref для обновления, но не вызывалась.
- Сравнения с `$null` приведены к безопасному виду (`$null -eq $x`).
- Тесты: убран неиспользуемый объект в тесте `Get-HttpErrorStatusCode`.

## Обновление

Вариант 1 — в самом меню: `[u] Обновить LDManager` (или `[g] GitHub → [3] Автообновление скрипта из GitHub`). С v2.0.8 автообновление работает и сверяет файлы по `SHA256SUMS`.

Вариант 2 — вручную: скачайте ZIP релиза и замените `LDManager.ps1`, `LDManager.core.ps1`, `LD.Sieve.ps1`.

> После замены файлов, если включена строгая политика выполнения (AllSigned), подпишите скрипты заново через меню `[s]`.
