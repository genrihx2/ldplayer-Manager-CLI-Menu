# LDManager v2.1.0

Изменения с v2.0.10.

## Изменения

- Новый пункт `[o] Оптимизация` в главном меню: пресеты «Экономный / Сбалансированный / Производительный / Максимальный» применяют CPU, RAM и разрешение одним действием через `ldconsole modify --cpu/--memory/--resolution`. Ручная правка по одному полю осталась в `[3] Конфигурация`.
- Значения подрезаются под реальное железо: ядер не больше доступных (и не больше 4), RAM — не больше половины физической и только из списка, который принимает `ldconsole` (256…8192). Если данные о железе получить не удалось, берётся безопасный профиль 4096 МБ.
- Перед правкой сохраняется резервная копия конфигов инстанса (`vms\leidianN\config.ini` и `vms\config\leidianN.config`) в папку `LDManager.instance_backup_*` рядом со скриптом — писать в папку установки LDPlayer не требуется.
- Результат проверяется: после `modify` значения читаются обратно из конфига, а не просто выводится «команда выполнена». Затем предлагается перезапуск инстанса.
- Тесты: 5 новых Pester-тестов на пресеты (слабая, мощная и одноядерная машина; формат разрешения; допустимые объёмы RAM).

## Обновление

Вариант 1 — в самом меню: `[u] Обновить LDManager` (или `[g] GitHub → [3] Автообновление скрипта из GitHub`).

Вариант 2 — вручную: скачайте ZIP релиза и замените `LDManager.ps1`, `LDManager.core.ps1`, `LD.Sieve.ps1`.

> После замены файлов, если включена строгая политика выполнения (AllSigned), подпишите скрипты заново через меню `[s]`.
